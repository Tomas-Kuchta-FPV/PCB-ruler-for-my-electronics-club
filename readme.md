# Thomases PCB ruler

So I run an electronics club in my chool and I want for the kids to have something fun. So I've figured that PCB rulers will cut ir, because we don't get many of these here.  
The front side has all of the basic schematic symbols, a ruller and a RFID detector.  
And what about the back side? It's pure ADHD riddeled with cool graphics, tables and more advanced footprints.
